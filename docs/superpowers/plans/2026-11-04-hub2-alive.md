# Hub 2.0, alive: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put the approved Higgsfield design and its motion on every Hub screen, behind the existing Hub 2.0 switch, ready for the Dec 13 flip.

**Architecture:** Theme and animate the ~20 shared parts every screen is built from (CSS in the two existing look files), add one small motion script for what CSS cannot do (ripple, gold wipe edge, note burst), one count component, then layer the mockups' signature pieces on top (Pieces 2 and 3). The self-check grows first in each task, so each task starts red and ends green.

**Tech Stack:** React 19, React Router view transitions, plain CSS (`@media screen`, `prefers-reduced-motion`), `npx tsx` self-checks, system Chrome over the DevTools protocol for screenshots.

**Spec:** `docs/superpowers/specs/2026-11-04-hub2-alive-design.md` (approved sketch: `docs/hub2-alive/concept.html`).

## Global Constraints

- Every rule is scoped under `:root[data-hub2="on"]` (public) or `:root[data-hub2="on"] .dir-app` (staff) and sits inside `@media screen`. Flag off must stay pixel-identical to main.
- No color literals in `hub2.css`, `hub2Public.css`, `hub2Staff.css` (no `#hex`, `rgb()`, `rgba()`, `hsl()`): colors come from `--hub2-*`, `--pub-*`, `--dir-*`, `white`, `transparent`, `currentColor`.
- Motion only under `prefers-reduced-motion: no-preference`; staff transitions and animations only inside that block (self-check §6).
- Page elements animate with fill mode `backwards` (never `both`/`forwards`): nothing may stay a layer once the motion is over (#hub2-motion).
- Only transform, opacity and clip-path move. No new dependencies.
- No em dashes or en dashes in anything the director reads (docs, commits, PR text, UI copy).
- Never style the hub classes (`hub2-*`, `pub-hall`, `pub-drill`, `pub-checkins`, the staff hooks) from a stock stylesheet.
- No merges on Nov 16, Nov 30, Dec 3, 9, 10, 12. Squash-merge only green and reviewed.
- Worktree: plain Bash commands only (no heredocs, no `$(...)`); `npm ci` before the first build.

/** The one motion gate: the look is on and the person has not asked for less motion. */
export function hub2MotionOn(): boolean {
  return document.documentElement.getAttribute(HUB2_ATTR) === 'on'
    && !window.matchMedia?.('(prefers-reduced-motion: reduce)').matches;
}

export function pageWipesOn(): boolean {
  return hub2MotionOn() && typeof document.startViewTransition === 'function';
}

```ts
/** The gold edge that rides the wipe. Hidden by CSS except while a View
 *  Transition runs, when it is named and its group sweeps across with the
 *  page. First in <body> so its group paints under the header and tab bar. */
function ensureEdge(): void {
  if (document.querySelector('.hub2-wipe-edge')) return;
  const edge = document.createElement('div');
  edge.className = 'hub2-wipe-edge';
  edge.setAttribute('aria-hidden', 'true');
  document.body.prepend(edge);
}

const TAPPABLE = 'button, a[href], [role="button"], summary, label.dir-checkbox-row';

/** Press: a ripple from where the finger lands, drawn in a fixed overlay at
 *  the target's box, so no component's own CSS changes. Removes itself. */
function ripple(e: PointerEvent): void {
  if (!hub2MotionOn() || e.button !== 0) return;
  const target = (e.target as Element | null)?.closest?.(TAPPABLE);
  if (!target || target.closest('input, textarea, select, [data-hub2-noripple]')) return;
  const r = target.getBoundingClientRect();
  if (r.width < 20 || r.height < 16 || r.width * r.height > innerWidth * innerHeight * 0.4) return;
  const cs = getComputedStyle(target);
  const host = document.createElement('span');
  host.className = 'hub2-ripple';
  host.setAttribute('aria-hidden', 'true');
  host.style.cssText = `left:${r.left}px;top:${r.top}px;width:${r.width}px;height:${r.height}px;border-radius:${cs.borderRadius};color:${cs.color}`;
  const dot = document.createElement('i');
  dot.style.left = `${e.clientX - r.left}px`;
  dot.style.top = `${e.clientY - r.top}px`;
  host.appendChild(dot);
  document.body.appendChild(host);
  setTimeout(() => host.remove(), 700);
}

/** Boot (main.tsx): one passive listener; every press asks the gate itself,
 *  so turning the look on or off takes effect at once. */
export function initHub2Motion(): void {
  if (hub2MotionOn()) ensureEdge();
  document.addEventListener('pointerdown', ripple, { capture: true, passive: true });
}

const NOTES = ['♪', '♫', '♩', '♬'];

/** Finish: a burst of notes from a success (checked in, form sent, roll
 *  saved). Called from each success path; does nothing without the look or
 *  with reduced motion. Removes itself. */
export function hub2Celebrate(from?: Element | null): void {
  if (!hub2MotionOn()) return;
  const r = from?.getBoundingClientRect();
  const x = r ? r.left + r.width / 2 : innerWidth / 2;
  const y = r ? r.top + r.height / 2 : innerHeight / 2;
  const host = document.createElement('div');
  host.className = 'hub2-burst';
  host.setAttribute('aria-hidden', 'true');
  for (let i = 0; i < 12; i++) {
    const a = -Math.PI / 2 + (Math.random() - 0.5) * 2.2;
    const d = 70 + Math.random() * 110;
    const s = document.createElement('span');
    s.className = `hub2-note n${i % 4}`;
    s.textContent = NOTES[i % 4];
    s.style.cssText = `left:${x}px;top:${y}px;--dx:${(Math.cos(a) * d).toFixed(1)}px;--dy:${(Math.sin(a) * d).toFixed(1)}px;--r:${((Math.random() - 0.5) * 70).toFixed(0)}deg;animation-delay:${i * 22}ms`;
    host.appendChild(s);
  }
  document.body.appendChild(host);
  setTimeout(() => host.remove(), 1800);
}
```

import { useState } from 'react';

/**
 * A number that rolls when it changes, under the Hub 2.0 look (#hub2-alive).
 *
 * The span takes the value as its key, so React mounts a fresh one for each
 * new value and its CSS animation starts again. The first value does not
 * roll: a page arriving is not a change. Only hub2Public.css styles
 * .hub2-count, so with the look off this is plain text in a plain span.
 */
export function Hub2Count({ value }: { value: number | string }) {
  const [seen, setSeen] = useState({ value, changed: false });
  if (seen.value !== value) setSeen({ value, changed: true });
  return <span key={String(value)} className={seen.changed ? 'hub2-count hub2-roll' : 'hub2-count'}>{value}</span>;
}
